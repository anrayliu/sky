# sky

Almost all of my private projects contain a modified version of this package. I'm finally cleaning it up and standardizing it, so I don't have to make 93420934 modifications to it for each project.

## features

- generic button class with css-esque customization
- game world camera
- sinusoidal screen shake
- flat state machine
- automatic delta time
- event handler
- asset manager (images and fonts)
- image caching for transformations
- post processing
